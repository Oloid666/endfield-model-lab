# 第五輪：跟隨、店內商品、進店鏡頭與介面

本輪沿用完整晚餐短劇，集中改善走路時的角色關係、店內陳列、鏡頭與渲染成本。以下記錄第五輪實作與本機驗證；發布狀態另列於文件末尾。

## 角色與鏡頭

- 龍泡泡使用獨立世界座標，記錄莊走過的路徑。跟隨包含短暫遲疑、追上、門口排成單列、繞貨架、讓路及停下後靠近；兩者保留身體間距。
- 莊的走路擺臂減小。肩、肘、腕使用不同相位和平滑速度；抱食物的一側減少擺動。衣服、頭髮與袖口仍使用原骨架的次級動作，沒有布料物理。
- 走進店內時，鏡頭先對齊入口，再從門楣下方跨入，之後轉為較廣的室內構圖。玩家拖曳鏡頭時保留手動控制。
- 感應門同時考慮莊與龍泡泡的位置，讓跟在後面的龍泡泡通過。

原始 GLB 沒有改動。程序動作只調整執行時姿勢；跟隨與找路限於店內及騎樓。

## 商品與海報

- 冰箱分為五區：水與氣泡飲、茶、鮮乳與乳飲、果汁與罐裝飲、輕食與優格。
- 陳列使用 40 種原創商品，包含瓶裝、屋頂紙盒、罐裝、三明治、沙拉與優格盒。尺寸、包裝、顏色與價籤分開設定。
- 商品依品類分區，以前後兩排、部分罐裝疊放及少量留白形成貨量差異。標籤與價籤共用圖集，商品使用實例幾何。
- 前窗加入四張原創插畫海報，集中在兩側，保留入口及中央視線。海報中的品項與價格為場景道具，不代表品牌現行促銷。
- 外窗保留靜態水珠與向下滑落的水痕，冰箱玻璃維持較乾。屋簷兩角增加細水柱，避免整面玻璃都像在流水。
- 透明食品外殼使用輕量反射邊緣與冰箱燈條高光；不為每個包裝重新計算整套 PBR 光源。

## 渲染與光影

- 場景燈光收斂至 14 盞，保留冷白螢光、暖窗、街燈與人物補光。招牌及燈帶繼續使用發光材質。
- 不透明場景依實際 HDR 支援使用最高 4× MSAA；省電最高 2×。後續玻璃、Bloom、色彩輸出與 FXAA 的全螢幕目標為單樣本，避免後製重複多重取樣。
- 雨絲位置由 GPU 依時間計算；初始化建立屬性後，不再逐幀重寫全部雨絲座標。
- 可共用的靜態 PBR 幾何以頂點色合批。活動門、人物、玻璃、貼圖與濕地材質保留各自處理。
- 車道與人行道仍共用低解析度反射。這是近似反射，不是每片地磚的獨立相機。

維持一個 Renderer 與主循環；故事、行走、跟隨、門片與雨水共用場景時鐘。

## 同條件效能抽樣

以 `scripts/profile-render.py` 比較 [第四輪基準](../artifacts/v4-render-baseline.json) 與 [第五輪結果](../artifacts/v5-render-profile.json)。兩版使用桌面 Chromium／SwiftShader、390×844 視窗、DPR 1、場景 4× MSAA 與 FXAA。每個視角先暖機，暫停連續動畫後取六個渲染樣本；每次以同步讀回一個像素等待該次工作完成，避免只量到 JavaScript 提交指令的時間。

| 視角 | 平均繪製呼叫：第四輪 → 第五輪 | 平均同步渲染時間：第四輪 → 第五輪 | 平均三角形數：第四輪 → 第五輪 |
| --- | --- | --- | --- |
| 街角 | 450 → 273.3，減少 39.3% | 1559.8 → 1366.5 ms，縮短 12.4% | 229,436 → 237,967 |
| 屋簷 | 223 → 172.7，減少 22.6% | 2366.4 → 2177.3 ms，縮短 8.0% | 194,529 → 207,862 |

合批與反射排程減少了繪製呼叫，這次抽樣的平均完成時間也縮短。三角形數則增加：商品幾何更完整，合批後的裁切範圍也較大。繪製呼叫減少不等於所有渲染成本都下降，不能據此宣稱整體效能已全面改善。

兩版抽樣的 WebGL 錯誤碼均為 0，未記錄 Shader 或 JavaScript 錯誤。每個視角僅六筆，且使用 CPU 軟體渲染與同步讀回；這是小樣本的版本比較，不是連續遊玩 FPS，也不能換算成 iPhone 的速度或穩定 30 FPS。

## 介面

五個視角收成約 286×54 的工具列，主要按鈕保留 44px 點擊區。開場按鈕、標題與對話框縮小，以金屬玻璃、細邊框及暖金選取狀態統一樣式。搖桿加入同心環與旋鈕；橫式對話固定右側，左側留給搖桿。

「聽雨」在結尾閒置時顯示；主線對話期間收起散步按鈕，已在散步時仍可停止。故事仍可收起暫停、重新選餐，選擇題持續等待玩家。室內構圖可縮小標題與操作列。
