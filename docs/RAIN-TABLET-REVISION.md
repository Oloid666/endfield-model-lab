# 雨夜：平板操作與雙事故

> 此頁記錄 16e7d75；最新流程與驗收請看 [操作與演出修正](RAIN-REPAIR-VALIDATION.md)。

新版正式雨夜啟用 `tabletMode`，賽車入口不變。所有平板按鈕共用同一狀態機；實體螢幕與下方輔助操作鍵做相同事情，離開視角也能完成操作。

- 冷鏈／電網兩項工作並列；先完成冷飲，電網項目會說明等待原因。
- PHP 閘道 → 冰箱控制器 → 設定溫度 → 強制除霜 +50°C → 梨花水放旁邊。過熱狀態維持至回放結束。
- 再開始微波爐：掃描 3 號天師樁 → NIKKE 啟動器示意螢幕 → 手動啟用後門 → 能量沿實體電線送至微波爐 → 800 W／800 MW → 確認 → 加熱。
- 800 W 可按且有回應，但不推進流程；連點有冷卻。掃描、工具套用、啟用後門與加熱均須玩家按鍵，不隨自動對話跳過。
- 初次節奏失敗先增加電弧，約五秒後紫色生物才噴出並顯示反應台詞；只生成一隻。保留貼地蠕動與點按變形，表面加上紫色漸層與濕潤高光，不增加透明疊層。
- 爆炸前先準備材質，等待時暫停劇情；準備失敗降為輕量畫質。最後一擊限制時間跳躍，避免長幀直接跳過演出。這不能保證所有手機固定幀率。
- 暫停與繼續在下方相同位置；背景、設定、載入各自保留暫停原因。
- 課堂保留八題，全部看完才結業；雙人補充對話合併一頁，顯示題號與本題頁數。評分仍使用原有 Cloudflare D1 收件流程，僅成功儲存才顯示收到回饋。

## 技術資料與戲劇加工

PHP2Shell 對應 CVE-2026-109618（OOM corruption）與 CVE-2026-109619（stale global state）；PHP 8.4.26 屬受影響版本，CVSS 4.0 為 9.2 Critical。

- https://www.cve.org/CVERecord?id=CVE-2026-109618
- https://www.cve.org/CVERecord?id=CVE-2026-109619

711 管理閘道、FrostControl 工具、天師樁後門及實際攻擊路徑為劇情演出，不連線任何真實設備。法國冰箱事件的實際入侵途徑未在本作品宣稱為 PHP 漏洞。賽馬娘停服關聯以角色轉述社群消息呈現；NIKKE 畫面為自繪事件示意。

## 驗證

`node scripts/vcr-tablet-check.mjs` 覆蓋手動關卡、錯誤功率、冷卻、暫停、重設及最後一擊長幀。既有 mission、director、bonus、feedback、analytics、攝影、街道、賽車檢查一併執行。

瀏覽器使用 Chromium 軟體 WebGL，驗證直橫向平板及全部按鈕、800 W 拒絕與加熱流程交接；此環境不能代替 iPhone Safari 真機效能驗證。可用 `PREVIEW_URL=http://127.0.0.1:4197/ python scripts/vcr-browser-check.py` 重跑；需先安裝 Playwright 與 Chromium 並啟動本機 preview，截圖寫入 `/tmp`。
