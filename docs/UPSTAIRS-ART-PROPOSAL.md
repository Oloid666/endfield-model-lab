# 二樓美術與分鏡提案：雨夜理賠所／笑點夜校

狀態：本輪完成設計，尚未改建二樓場景。沿用現有6×5公尺切面房間、角色與共用renderer，先做一張保險室、一張學堂的代表畫面，再分批實作。

## 共用美術系統

- 用墨綠牆裙 `#29443d`、暖灰牆面 `#8d9587`、深胡桃木 `#604d39`、霧黃銅 `#ad9360`，延續雨夜711，而不是另換一套遊戲風格。
- 地板改成有寬窄、接縫和少量磨損的木地板；踢腳板、門框、窗框有厚度與圓角。粗糙度有區分，避免所有物件像同一種塑膠。
- 窗外雨藍、室內暖燈形成兩層深度；一個主要光源加柔和補光，手機不新增點光源陰影或即時景深。
- 桌面和牆面約保留四成空白；細節集中在鏡頭會拍到的區域。小物件以程序幾何、共用材質、局部Canvas貼圖製作。
- 保留現有手機上方演出／下方閱讀的分工；桌面使用較寬場景。每個重要表情或道具鏡頭均預留字幕與按鈕位置。

## 保險室：武陵雨夜理賠所

### 空間與道具

主桌放在後方偏右，左側雨窗作藍色輪廓光，龍泡泡在前景左側，理賠員在後景右側。桌面中央留給案件、保單與手部動作。

| 區域 | 精選裝飾 | 畫面用途 |
|---|---|---|
| 主桌 | 黃銅桌牌、暖罩桌燈、印泥、毛氈蓋章墊 | 材質層次與公務感 |
| 文件區 | 有厚度的案卷、帶折角申請書、兩枚紙夾 | 真正被拿取、蓋章的工作物件 |
| 後牆 | 一張保單框、一小列案件櫃、日期章 | 維持整齊，避免文字海 |
| 窗邊 | 半杯熱茶、濕傘架、窗台積水痕 | 交代同一個雨夜 |
| 喜劇細節 | 小型「本日已處理 0 件」翻牌 | 一個可被近景看懂的梗，避免滿牆標語 |

### 四個固定鏡頭

1. **進門建立，2秒**：從門框與桌燈之間斜看房間，龍泡泡入鏡，理賠員抬眼；用走位帶出空間。
2. **越肩交涉**：從龍泡泡肩側看理賠員，眼睛在右側約62%；用較窄FOV壓縮桌面與後牆距離，保持穩定。
3. **文件／蓋章近景**：鏡頭推近申請書、壓章、紙張輕彎與印泥壓痕；章落下才給短促回饋。
4. **逆轉表情**：理賠員看懂條款時切面部近景，再回龍泡泡停半拍。笑點靠表情和時序，不靠持續搖鏡。

## 笑點課：雨夜社區小教室

### 空間與道具

黑板位於後牆偏左，講桌與龍泡泡在右側，前景只留一張課桌的一角。窗邊藍光與講桌暖光沿用理賠所，讓兩個房間屬於同一棟房子。

- 黑板增加厚木框、粉筆槽與擦拭痕。每頁只呈現題目、關鍵字或示意圖；完整說明留在可閱讀的介面。
- 講桌放粉筆罐、板擦、打開的備課本與一只馬克杯；桌角有少量磨損，不堆滿文具。
- 前景課桌放一本筆記、鉛筆與兩條手寫重點；窗邊一盆小植物，牆上保留時鐘和一張課表。
- 趣味細節採一張小尺寸「不要把笑話講解到死」便條，其他牆面留白。

### 四個鏡頭與觸發

1. **開課全景，1.8秒**：透過前景課桌與筆記看黑板，龍泡泡從側邊入鏡，拿起教鞭。
2. **講解中景**：臉、教鞭與部分黑板同框；角色做指示、眨眼、停頓，閱讀時鏡頭停穩。
3. **重點插鏡**：只在公布答案時切黑板重點；粉筆圈線出現後保持，不播放無止盡裝飾動畫。
4. **課後吐槽近景**：龍泡泡表情佔畫面較高比例，留半拍，接一句吐槽，再回閱讀畫面。

## 建議實作順序與驗收

1. 先做共用牆、地板、窗框、燈光與一組桌椅材質，提供直屏／桌面對照。
2. 完成保險室主桌、文件與蓋章鏡頭，再加入三至五個精選裝飾。
3. 沿用共用素材改造學堂，接上講解、重點、反應鏡頭。
4. 每室新增道具材質控制在約12組內，靜態小物合併，避免增加初始下載；二樓資源仍依既有入口準備。
5. 驗收390×844、844×390、1366×768：表情與工作道具可辨識，黑板可讀，UI不壓人物，手機實測另記錄。八題進度與理賠操作沿用既有流程。
