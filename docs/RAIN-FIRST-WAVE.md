# 第一輪：人物動作、鏡頭與相機快門

後續托盤承托與交接、同一張照片裁切等修正以 [晚餐演出與操作修正](RAIN-DINNER-REVISION.md) 為準；以下保留第一輪歷史紀錄。

延續現有 Three.js 0.180.0、模型、劇情與操作。使用專案內 `game-cinematic-camera` 的動機、可見性、共用時鐘與獨立審閱流程；按鈕沿用 StageShow 導入後的原生 CSS。第二輪12項、保險與學堂場景留待下一輪。

## 已實作

- **1–2 拿餐與交接：**餐點以指根／掌心與實際手腕姿態承托，盒身跟隨手腕。龍泡泡回到原站位後停留1.4秒，依接觸、承重、移交、持穩順序交接餐袋，再顯示手持餐點；時間來自購物路段，等待自動門不會提早觸發。加入手部接觸近景。
- **3–4 走路、起停與轉向：**世界座標支撐腳、預估落腳點、抬腳與腳掌輕微滾動；急轉降低重心、身體前傾依加減速變化。保留速度與碰撞。零時間更新不重設步伐或手臂。
- **5–6 升空與後座：**沿用現有升空／落地時程，區分雙腿收身、懸浮與落地回穩；加強手臂、脊柱和衣物既有骨架的後座傳遞，未改命中時間與既有燈光。
- **7–9 簡報與機櫃：**「流程好幾年」改莊方宜胸上反應近景。機房證據對準實際窗內模型，書堆以斜角透窗看。倖存機櫃先廢墟遠景，再從倒下招牌下方拍亮燈近景，最後緩拉開。
- **10 確認照片：**雙人構圖接肩外手機；龍泡泡移到側邊，避免擋住手機。不沿人物環繞穿進雨棚；拍照自由控制與照片三按鈕保留。
- **11 供電：**管理電腦只發控制指令。實際第三座天師樁新增輕量輸出接點，電線起點取得該物件世界位置。0–0.4秒確認指令、不放電；0.4–1.6秒拍輸出；1.6–4.9秒沿線；4.9–6秒拍微波爐接收。減少動態使用三段固定機位剪接，同一條線與相同時序。
- **12 載入：**首次遊玩也能在「載入詳情」按「直接進入」。提早按只排隊，實際角色及著色器就緒才結束載入；錯誤時保留重試，重試成功後仍完成原排隊要求。完成清理只執行一次。

## 程式與驗證方式

動作集中於 `performance.js`、`locomotion.js`、`shopping-journey.js`；分鏡由 `story-shots.js` 與既有 `mission-director.js` 接管；供電沿用 `tianshi-grid.js`、`vcr-effects.js`、`vcr-tablet.js`；介面與載入為 `investigation-ui.js`、`button-materials.css`、`loading.js`、`opening-timeline.js`。沒有新增後端、公開 API、套件或模型檔。

- `npm run build`；原有大於500 kB chunk提示仍存在，未因此調整部署或依賴。
- 實際 GLB 骨架45項：支撐腳連續步進不跳動、暫停保留腳／手臂／步伐、走路踝關節目標誤差約9.1 mm；這不是畫面流暢度量測。
- Director483項，含正常及減少動態的整段電線能量投影；載入27項；共33套 Node 檢查通過，涵蓋既有劇情、手機操作、照片、資安平板、碰撞、保險／學堂等回歸。
- `scripts/first-wave-browser-check.py`：真正主線至拍照、交接、雙人／肩外、指定簡報節點與倖存機櫃。320×568、390×844、844×390、1366×768 的快門等寬高且無按鈕內文，保存實景截圖。
- `scripts/wire-framing-browser-check.py`：實際七下招牌解鎖、妮姬對話後接電，保存控制、源頭、沿線、接收的實景。`REDUCED=1` 與 `WIRE_WIDTH`／`WIRE_HEIGHT` 可驗證減少動態及橫向。
- `scripts/loading-entry-browser-check.py`：暫停真正的 GLB 請求、提早按直接進入、解除後入場；再注入一次下載失敗，確認重試成功後入場。
- 既有 UI 瀏覽器198項檢查通過，包含三按鈕、設定焦點、字幕字級、暫停恢復、平板及評分。使用 Chromium／SwiftShader；iPhone Safari 真機、GPU效能仍需驗收。

獨立唯讀審閱找到並修正支撐腳瞬移、零時間步伐重設、快門焦點優先序，以及近景推進方向。實景審閱另修正雨棚遮擋、招牌擋機櫃、微波爐偏出接收鏡頭。最後一輪獨立代理因額度停止；其後的截圖與回歸由主執行者完成，不能視為完整的真機驗收。
