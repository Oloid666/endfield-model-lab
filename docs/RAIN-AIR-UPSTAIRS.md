# 高空接餐與二樓美術更新

依使用者確認：接晚餐為純演出，取消👀符號；莊和龍泡泡維持高空，保險室與教室一起改善。沿用 Three.js 0.180.0、角色模型、理賠流程、八題內容及既有單一 renderer，不新增玩法或外部素材下載。

## 高空拋餐：12秒後恢復發射

| 時間 | 分鏡／動作 |
|---|---|
| 0–1.5秒 | 空中抓握中近景，龍泡泡掙扎並提醒不要浪費食物 |
| 1.5–4.5秒 | 地面近景與短距離跟拍，生物抬眼、停頓、爬到落點；依序✋、😌、🍱、🫴 |
| 4.5–5.5秒 | 上下關係全景：空中的晚餐和地面接餐者同框，角色不下降 |
| 5.5–7秒 | 唯一托盤從真實掌面位置放手，以可重播的拋物線落下；相機跟著晚餐，不繞圈 |
| 7–8.2秒 | 小觸手努力接住，身體受重縮扁、回彈後站穩；原食物留在托盤內 |
| 8.2–10.1秒 | 👌確認，接著實體小手與👍；穩定近景留閱讀時間 |
| 10.1–12秒 | 晚餐放低護住，鏡頭回空中抓握；12秒後顯示並開放原發射條 |

托盤持有人為龍泡泡→`air`（飛行中）→紫色生物；飛行中不能提前交給生物或落回莊手上。拋出起點從當幀支撐平面取得並固定，接觸後掌墊與盤底共用同一座標。紫色生物身體保持低矮，觸手只需伸到約0.64公尺，不再拉成高柱。原本落地後接回晚餐的流程保留。

莊抓龍泡泡與龍泡泡托晚餐使用分開條件；送餐後仍抓住紅色把手。抖動先旋轉角色，再校準把手至腕部；發射游標越靠近中央金區，抖幅越強。UI和攝影機不跟著抖；暫停不消耗時鐘。主砲／電網弱光窗口與12秒解鎖同步，保留減少動態效果設定。

## 雨夜理賠所與笑點小學堂

依先前雙場景概念圖實作共用墨綠牆裙、暖灰牆、胡桃木紋、霧黃銅、木地板接縫、窗框與雨夜藍光。保留簡化角色原貌；資源以程序幾何與256px共用木紋產生。窗面雨絲使用實例，不新增陰影貼圖、景深或第二個renderer。

- **理賠所**：桌面與桌體圓角、綠罩暖燈、毛氈蓋章墊、案卷紙夾、小文件櫃、保單框、傘架，以及「本日已處理0件」小桌牌。刪減原三幅編號牆飾、縮小桌前標牌，讓文件與交涉成為焦點。
- **小學堂**：加寬講桌、移開遮眼檯燈、備課本、粉筆罐、板擦、植物與前景筆記。便條移到黑板外牆，不壓題目；黑板字保持閱讀空間，詳細解析仍由既有介面呈現。
- **鏡頭**：理賠入場全景→說話者中近景→要保人反應→紙張／蓋章近景；教室全景→黑板重點→龍泡泡臉部吐槽特寫。鏡位與FOV都以時鐘平滑過渡，減少動態效果時直接定位。
- **互動**：保留理賠五欄、異議、三章、八題完整進度、死亡證明、評分、閱讀模式與返回街景。圓角幾何仍保留原本單位尺寸／scale語意，避免破壞紙張、印章及嘴部動畫。

主要模組：`tray-rescue.js`／`performance.js`處理高空交接與抓握，`story-shots.js`配合演出鏡頭；`upstairs-art.js`提供共用材質與裝潢，`bonus-room.js`沿用原功能配置美術與近景。增加的公開可讀資料只有`air`持有人、抓握抖幅與二樓相機FOV；無存檔格式、資料庫或部署設定變更。
