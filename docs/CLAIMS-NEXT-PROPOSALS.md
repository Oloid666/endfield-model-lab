# 理賠中心下一版玩法提案

此檔是提案，尚未替換目前 A／B 玩法。方向是輕鬆操作、角色互動，以及不必把全部附件或欄位看完。

## 首選：理賠談判桌

玩家是夾在莊、店員和龍泡泡中間的臨時調解員。三個回合，每回合先聽一個要求，再在固定位置選「照實處理」或「幫她圓一下」，兩種都能繼續。沒有答錯重做，不逐欄填表。

1. 莊要求把主動雷擊列為天災。照實寫會被問「字可以小一點嗎」；幫她圓則被店員要求在天氣欄補姓名工號。
2. 店員要求修便利店，莊只確認梨花。可把建物列入，或先拿一張荒謬的「梨花完好證明」，角色當場談判。
3. 龍泡泡要求彈藥工傷補償。可核發便當照護券，或先補一份「自願飛行同意書」，換來龍泡泡抗議。

約 2–3 分鐘，最後出一張武陵和解書，列出重建、晚餐和龍泡泡待遇。結果隨選擇不同，但不以真實保險法規或理賠金額計算。重玩可以改選，看不同角色反應。

推薦理由：有少量真正的玩家決定，又比找附件、逐欄填單省力，和教室的單純解析有不同節奏。

## 次選：保險公司請翻譯

莊用三句公文描述事故，玩家在同一位置按「翻譯成人話」。例如「晚間環境改善」翻成「便利店被拆了」；「梨花無損失」翻成「其他東西先不要看」。每句揭露一段現場對照，最後蓋「請補件」。

約 1–2 分鐘，一個主按鈕即可完成。選單可切成「替莊美化」版本，看另一組吐槽。優點是最輕鬆；缺點是玩法較接近小教室，玩家決定較少。

## 第三案：離譜申請快審

每次來一張短申請，玩家按固定的「受理／退件」兩個大按鈕。三張即可收工，另有兩張自由加班；不同選擇都會得到一兩句角色回應，不限時、不扣分、不強迫重試。

申請例：龍泡泡要求彈藥工傷、微波爐申請全城電費報銷、店員要求屋頂加班費。最後印出本日辦案小結。優點是有連續操作感；需要避免變成只猜作者標準答案的考試。
