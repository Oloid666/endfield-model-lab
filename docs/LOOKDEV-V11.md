# V11 · 龍泡泡先到場、櫃檯與報平安相機

本輪依最新定稿執行，舊版照片二選一不再是主線入口。

## 流程與演出

- 龍泡泡獨立建立，莊模型下載時已可看見跳躍、轉身及等待文案。模型到場後接回同一隻程序角色，不另建 Renderer。完整街景初始化仍有成本，不宣稱瞬間顯示或 iPhone 載入時間已縮短到特定秒數。
- 修正透明載入層仍攔截按鍵的問題：完成後真正隱藏並停用命中。載入顯示目前／總量 MB 與百分比；兩份 GLB 的總量取自既有固定原始檔大小。MB 使用十進位，下載後另顯示解析與光影階段。畫面標記 iPhone 直屏優化。
- 首頁從櫃檯看人物；開始後龍泡泡飛到櫃檯拿餐。買完沿前側走道、自動門、騎樓移動，再由龍泡泡拿手機飛到拍攝位置。
- 相機加入快門圓鈕、對焦框、倍率按鍵、照片預覽與送出。台詞引導拍入 711 招牌；不檢查必拍線索，不要求重拍。
- 送出後手機翻到相簿上一張息壤簽收單，顯示萬噸、經辦莊與簽收龍泡泡。背鍋對話完成後，龍泡泡在現場注意二樓，再進通訊。簽收單是本作製作的虛構圖像，不冒充玩家剛拍的照片。
- 登入與驗證時莊不飛；「我不是機器人」先說完對話再顯示操作，完成後回到角色短反應，再進拉桿。拉到底才出起飛許可並快速升空，龍泡泡在後續充能及砲擊跟隨莊。
- 說「伺服器呢？」時取景運作中的機櫃。最後一發後避免提前特寫卡住的泡泡，結尾順序為伺服器破洞、莊微笑、廢墟及招牌、隔壁卡住的龍泡泡。最後出「武陵城又過了平安的一天／可喜可賀」。破洞以暗色底與碎裂邊緣呈現，沒有宣稱真實布林破壞或物理模擬。

## UI 與互動

- 移除自動對話與跳過按鈕。一般對話點擊繼續；連續演出仍由劇情時鐘推進，可暫停。
- 自動運鏡按鈕直接恢復演出；拖曳可停止自動。通訊內包含莊的回答。龍泡泡用固定角色框，砲擊時反應另放操作面板外。系統與角色文字分開。
- 直式角色框與鍵盤限制高度，操作結束便退出該面板；主線時收起底部視角列，避免和字幕疊在一起。登入加入「下班」「找管理員」等非必要鍵，短吐槽不清空進度。
- 「店前／屋簷」合併為「店內」。該視角局部隱藏近側門框、玻璃遮擋和上方建物，離開後恢復。保留店內櫃檯、貨架及微波爐，不把整棟設成透明材質。
- 點門面切換門；人物接近仍優先自動開門。點二樓窗燈切換亮暗，點紅綠燈循環紅、綠、黃，光源顏色跟隨變化。拖曳不觸發。
- 弭弗 A 從原選款圖裁出專用 320×400 JPEG，保留原圖；內嵌 64×80 同肖像備援，圖片請求失敗仍有肖像。修正原本針對三款合圖的 450% 裁切 CSS。
- 賽希從照片預覽階段開始預載，開場不與莊一起下載。現有 GLB 仍需完整 8.03 MB，未宣稱新增分段模型下載或壓縮版本。

## 定稿文案

- 海報：「黎諾說：沒有洗腦。／魔族佬黑：不注重食品衛生」；「小蔥傲嬌讚！／嘴上說不用，第二件還是拿了。」；「武陵補給祭・集點開跑／消費一筆蓋一格。萬噸仍算一筆。」
- 「附近沒有目擊者」取代撤離句。保險採已備附件、只等填事故時間的預謀版本。
- 耗電加入「電量告急，將軍救急！將軍出手，萬事大吉～」「你錯棚了」。
- 賽希先想「人不該等便當」，再調供電。PHP 設為戲內 `2026.10 NEW` 維護後台驗證漏洞，免金鑰取得最高權限；關於頁標明架空設定，不當作真實 PHP 或 CVE 公告。

## 驗證與邊界

- `npm run build` 與 Repository base 建置；保留 Vite 大於 500 kB 的主 bundle 提醒。
- 故事狀態、起飛時機、角色骨架、破壞、道具、鏡頭、資源及著色器檢查。狀態 55、鏡頭 63、道具 51、骨架 69、破壞 36、特效 25、著色器 15 項通過。
- 實際桌面 Chromium／SwiftShader：櫃檯、走出門、拍攝、送出、簽收單、通訊、地面登入、分離驗證、拉桿、充能、砲擊、VCR、節拍、返回、終末彈與結尾；另觀察結尾六十秒。
- 6 項實際點擊門、二樓燈與交通燈測試通過，包含拖曳不誤觸。
- 8 項故障處理測試通過：首次模型回傳 HTTP 503 後重試；頭像 JPEG 回傳 HTTP 503 時使用同肖像備援。
- 桌面與合成輸入不是 iPhone Safari 真機測試。未宣稱真機穩定 30 FPS、實際手機載入時長或完全消除穿模。

最終 `index-CbRnhtz7.js` 完整桌面流程 32 項通過，無 JavaScript 錯誤；結尾實際觀察 60.06 秒。證據為 `artifacts/v11-browser-results.json`。
