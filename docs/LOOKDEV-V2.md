# 第二輪場景質感修訂

使用者要求對照雨夜 711 參考頁，改善光影、玻璃、反光與樹木。本輪只修改場景，不加入故事或走路。

## 本輪改動

- 降低平均環境補光，改用店內燈、招牌、壁燈、街燈形成明暗層次。保留人物正面補光。
- 增加夜間環境反射。櫥窗使用一次擷取的街景立方體貼圖，依觀看角度改變反射強度。
- 標準與省電玻璃保持透明，讓商品能看清；細緻畫質使用完整透射。細緻透射目標以 0.75 倍畫面尺寸渲染，標準不增加透射場景渲染。
- 打開側面櫥窗，補金屬框、細小玻璃水痕、商品包裝、窗簾與室內剪影。
- 濕地反射改用世界座標生成水窪分布、細小擾動與粗糙區域。用五次低解析度取樣柔化反射，取代整片相同清晰度的鏡面。
- 增加牆面、地磚、木紋的原創程序貼圖；貼圖只在初始化時建立。
- 將兩棵球狀樹冠改為分枝與 3,168 片共用幾何的實例葉片。保留葉片之間的空隙。
- 增加一張快取的店前陰影圖，隨畫質使用 512／1024 尺寸。靜態街景不逐幀重畫陰影。
- 立面改為帶欄杆、水塔與空調的平屋頂老樓，補上發光招牌細節。

只使用一個 Renderer 與主循環。玻璃立方體反射只在初始化及 WebGL 恢復時擷取；資源納入釋放管理。

## 驗證限制

iPhone Safari 真機仍待測。軟體 WebGL 的桌面結果不能用來宣稱手機穩定 30 FPS。細緻玻璃增加渲染成本，因此不作為手機預設。

## 本輪測試結果

- `npm run build` 與 Pages 子路徑建置通過。
- 桌面 Chromium／SwiftShader 的 21 項檢查全部通過，包括省電／標準／細緻切換、模型載入、鏡頭、直橫式、失敗提示與 WebGL 中斷恢復。
- 最終標準模式持續觀察 60.1 秒，沒有 JavaScript 例外。
- 1440×1000 的軟體渲染約 0.50 FPS，未達 30 FPS。這不是 iPhone GPU 的效能結果。
