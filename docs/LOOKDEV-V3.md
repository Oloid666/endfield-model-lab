# 第三輪：人物可讀性、店內動線與自然待機

依使用者回饋，修正斑馬線方向、人物逆光、貨架配置與呆板姿勢。本輪仍是場景驗收；尚未加入劇情、選餐、多結局或走路。

## 實際修改

- 斑馬線穿越車道，兩端接上人行道坡道。車道標線、路緣與排水溝讓出穿越位置。
- 降低室內燈與招牌溢光，移開人物頭頂強光。以獨立正面主光及冷色補光保留臉、衣服與頭髮細節。
- 店內改為後排冰箱、兩組低雙面貨架、右側收銀台及後方微波爐。後方通道約 0.93m，入口不被貨架或門檻堵住。
- 加入原創商品包裝圖集、瓶身、瓶蓋、價籤與冰箱門。商品使用共用材質及實例幾何。
- 玻璃改成共用場景色彩與深度的薄玻璃 Shader。依角度反射街景，保留細水痕與少量折射；深度檢查避免玻璃覆蓋前方人物。這取代第二輪細緻模式的全場景透射。
- 人物使用同一個 58 秒表演時序：先看商品、再看龍泡泡、整理袖口、抬眼看雨、緩慢吐氣。眼睛領先頭部，動作間留白。
- 小幅換重心時，用骨架運算維持雙腳位置與方向。原 GLB、比例、材質與骨架結構均保留。
- 龍泡泡探頭、看主人，遇到指定滴水後縮身靠近她。這些反應與場景時鐘同步；關雨後停止避雨反應。
- 近景收起底部文案，縮小工具列，保留人物腳部。雨絲依店燈及路燈距離改變明暗。

仍只有一個 Renderer 與主動畫循環。玻璃反射立方體僅初始化及 Context 恢復時擷取。程序貼圖、商品及樹葉不在每幀重建。

## 驗證

`scripts/browser-smoke.py` 於桌面 Chromium／SwiftShader 通過 27 項檢查。詳細資料在 [qa-results.json](../artifacts/qa-results.json)。包括：

- 原模型與骨架、玻璃色彩／深度、三段畫質、視角與設定。
- 直橫式無頁面溢出、近景文案收合、單指拖曳、模擬隱藏時鐘暫停。
- 以人物半徑檢查入口至冰箱及收銀台的路徑。
- 七個抽樣姿勢的頭部與手腕姿態確實改變，腳部最大偏移約 2.5mm。
- 場景持續觀察 60.08 秒，沒有 JavaScript 或 Shader 例外。
- 真正觸發 WebGL Context Lost／Restored、模型失敗與 WebGL 不可用時的提示及恢復。

軟體渲染桌面 1440×1000 約 0.52 FPS。此環境未達 30 FPS，也不能代表 iPhone GPU。iPhone Safari 的效能、溫度、工具列高度與背景恢復仍待真機測試。

`npm run build` 及 `/endfield-model-lab/` 子路徑建置通過。單一 JS chunk 仍超過 500 kB，Vite 警告保留。
