# 雨夜：六段分鏡、洛西收藏與散步

正式網址：https://endfield10000t.aura87.online/ 。本輪接續 e2809c6；沒有新增後端、公開 API、資料庫欄位或署名功能。

## 本輪新增

- 六段分鏡由 `story-shots.js` 統一決定最後鏡頭：輸電、冰箱反轉、主嫌簡報、紫色生物誕生、開場、充能保險對話。人物取景使用實際頭部位置；閱讀與操作期間停穩，其他分鏡維持。
- 輸電亮頭與相機共用 `wireProgress`，總長仍為六秒，末段減速後抵達插座才開放選功率。一般模式直接跟隨平滑電線路徑，避免第二次相機緩動造成亮頭出框；減少動態模式使用固定機位。
- 冰箱反應時塞西稍微轉身、抬頭，龍泡泡移到走道避開櫃檯；保留降溫再反轉與完整兩句歌詞。紫色生物出生前拍便當與電弧，出生後才拍完整生物。
- 洛西是依已確認紅帽造型製作的原創簡化同人手辦：956個三角形、單一網格與頂點色材質、一次繪製。無外部模型／貼圖下載、骨架或獨立陰影。原收藏色柱改為手辦與書本，收藏角隨房屋實際損壞落地、復原回位。
- 平板先交代管理密碼，再找其他入口；操作鍵改白話，技術名保留在畫面。課堂顯示全八題的已確認閱讀進度，重看不重複計算；課後吐槽改為「妳好意思比御坂美琴多一級？」。
- 通關後紫色生物以0.35m/s跟隨、遠距離0.48m/s追趕，抵達後以0.2m/s在附近爬動。龍泡泡獨立巡遊、看街景，取消地面跟隨者對莊的阻擋。兩者共用原地圖邊界與門／家具導航；演出、背景暫停與重開均正確交接。

以下保留先前手機操作與劇情修正的設計紀錄。

## 劇情與時鐘

塞西先想喝氣泡水加梨花冰沙，看到冰箱不夠冰，才搜尋降溫方法。平板的「指令已送出」與冰箱的「實際溫度」分開；冷卻兩秒從 +4°C 到 −8°C。兩句成功反應由玩家閱讀，之後停半拍，再在三秒內升至 +50°C。除霜與法國預設模式到反轉時才揭露。

保留「……法國🇫🇷駭客工具，預設模式忘了改。」及完整兩行「熱愛105°C的你～🎶／滴滴清純的蒸餾水～」。取消冰箱開門、取瓶與放瓶；塞西回櫃檯讀實體「800 W／3分鐘」標籤，再搜尋加速方法。平板畫面與實體點擊按鈕從相同狀態生成。

天師樁先有設備與管理電腦的建立鏡頭，再拍妮姬螢幕。拉毗露臉問「可以幫我打馬賽克嗎？」；龍泡泡的「可以！」出現 0.7 秒後才遮眼，停滿一秒才開放後門按鈕。黑條畫在螢幕貼圖內；只在狀態改變、素材載入時重畫。此狀態隨任務時鐘停止，重開清除，延遲載圖不會抹掉黑條。

發射後拍莊喊 Explosion；爆炸後才接「我早想喊看看了。」及龍泡泡的「爆裂魔法個頭啦！」，字幕位置避開人物投影與介面。舊台詞 ID、八題課程維持，新增解析使用第三個微波爐段落，課程頁數同步計算。

## 觸控、版面及恢復

手機通訊頭像為 40×44 CSS px，取消多餘章節列與波形；字幕字級保留 18／22／26，行距 1.5，直向框最高 32dvh。長文可捲動，拖曳不推進台詞。進度區為 48px。

按鈕與操作區禁止選字和 iOS 長按選單；輸入欄仍能選字、複製貼上。前進／後退分別處理正常放開與取消，取消不額外短步。暫停、失焦、移除控制區會解除長按與指標捕捉。

二樓有自己的原生恢復對話框，位於可操作區內，避免主線的 inert 與 bonus 暫停原因造成死鎖。繼續僅解除背景／手動暫停，保留主線的 bonus 暫停。重播只重設本幕鏡頭與未完成轉場，保留課程、評分、留言表單及請求去重資料；舊轉場使用世代號，取消後不能回寫新畫面。

## 模型及場景

OK繃以曲面幾何沿龍泡泡身體表面貼合，放大四成，跟隨呼吸與轉身。已出生生物在廢墟使用店前安全地面位置；正常通關、拆屋、復原均維持同一個物件，捷徑不產生未出生生物。冰箱面板、紅燈、霜與蒸氣共用設備可見性，倒塌與重建演出也同步更新。

## 驗證

- 本輪31組相關 Node 檢查涵蓋單網格手辦、全課進度、暫停／演出交接、室內外碰撞與緩慢巡遊；相機檢查逐幀驗證亮頭在視野內，瀏覽器另確認實際模型沒有擋住主體。
- 新舊版在相同低畫質街景取景下比較，素材請求清單相同；總繪製呼叫692 → 688，總三角形465,143 → 466,815（含多次場景繪製）。這是資源比較，不是手機幀率測試。
- Node 檢查涵蓋完整故事、課程、模型、相機、品質切換、後端回饋，以及新增的長按取消、鍵盤啟動與貼片不穿模檢查。
- `scripts/vcr-browser-check.py` 以 Chromium SwiftShader 驗證實體平板、降溫反轉、完整歌詞、遮眼時序、節奏恢復、發射鎖鏡、首次復原、理賠、八題課程、評分草稿、謝幕恢復、六次房子切換及實際鍵盤走到馬路。
- 背景切換是受控 visibilitychange 事件，不能取代 iPhone Safari 真實 App 切換；iOS 的選字選單同樣需要真機驗收。軟體 WebGL 結果不代表手機幀率。
