# 晚餐、105°C與紫色保管員

本輪延續 Three.js 0.180.0、現有 GLB、劇情與單一渲染器。工作起點為 `480283c`；只發布 `ui-preview` 預覽，正式 `main` 不變。此文件取代上一輪救餐9秒與誕生5.2秒的時序描述。

## 完成內容

- 龍泡泡實際領餐、走回並交好托盤後，才說「買完了，來吃吧。」；留2.6秒看餐點再進拍照，不增加點擊步驟。快按、跳句與背景暫停均不能提早播出。
- 莊的餐點加入厚照燒雞腿、帶皮炙燒鮭魚、脂紋、玉子燒、蔬菜、米飯、加蓋湯與封套筷子。墨綠、霧金、米白與食物暖色延續店內美術；保留唯一一份實體托盤。程序主餐25個mesh、39,014三角形（含實例），沒有新增外部模型或圖片下載。
- 冰箱、平板、台詞及課程回顧統一為 **+105°C**；仍先降溫再反轉。蒸氣改為12個共用柔邊貼圖實例，從冰箱上方升起，避免擋塞西與溫度顯示。完整保留兩句105°C歌詞；只有該段龍泡泡雙手／麥克風隱藏，後段演唱恢復。
- 紫色生物改為不對稱凝膠身體、眼神、兩條彎曲觸手和獨立掌墊。身體維持低矮；伸手、受重、縮扁及👍均以同一劇情時鐘演出。表情符號不攔截觸控，原生字型支援手機emoji。
- OK繃與髒污持續保留至彈指，2.6秒真正觸發後一起飛散／淡出0.35秒；重建房子、進街角與切換階段均不提前清除。

## 分鏡／動作時間表

| 時段 | 用意與畫面 | 動作、銜接及控制 |
|---|---|---|
| 買餐完成 | 托盤斜俯近景，雙主菜、湯和手掌同框 | 購物狀態完成才說買完了；2.6秒後回拍照對話 |
| 誕生0–4.5秒 | 微波爐食材特寫，慢慢鼓起 | 先焦黑，再逐漸融合；不直接跳出成品 |
| 4.5–7秒 | 靠近爐口，眼睛探看 | 6.2–6.8秒門開到約86°，為爬出留空間 |
| 7–9.5秒 | 跟爬到檯緣，機位交代地面方向 | 成分已融合，原食物消失，沒有第二份食材 |
| 9.5–11.5秒 | 落地／回彈後停穩 | 落點在檯前地板；停穩才進塞西拒絕梗 |
| 最後一發0–2秒 | 空中護餐，切地面注意近景 | 👀有1.2秒；攝影機不靠旋轉製造動態 |
| 2–4秒 | 低機位跟隨短距離爬行 | ✋→😌；三小時回放後牠已在現場附近，路程約2公尺 |
| 4–6秒 | 全景交代莊垂直降下 | 🍱→🫴；保持水平方位，托盤下降到約1.25公尺，莊仍抓住龍泡泡 |
| 6–8.8秒 | 觸手／盤底中近景 | 第一次差一點，縮回後第二次拉長；兩掌頂面與同一托盤使用同幀座標 |
| 8.8–9.5秒 | 壓重、站穩，鏡頭停穩 | 身體縮扁；接到後龍泡泡才鬆開托盤，莊持續抓住龍泡泡 |
| 9.5–12秒 | 保管員反應近景 | 👌→👍，有實體小手；降低主砲／電網光效干擾 |
| 12–14秒 | 安全放低晚餐 | 生物降低托盤並護住，保持空間方向 |
| 14–17秒 | 跟莊回到發射高度 | 莊垂直升起；17秒後才開放發射條，不可提早發射 |
| 落地接回 | 沿用單一托盤接回鏡頭 | 持有人：莊→龍泡泡→生物→莊；無重複餐點 |

相機與角色皆沿用既有 Camera Director；`story-shots.js` 配合共用出生／救餐時間表取樣，畫面依直屏、橫屏和桌面HUD安全區調整。移動使用時間取樣與平滑緩動；背景暫停、重新開始及debug跳轉清除演出快取，保留原本操作恢復流程。

## 程式入口與Skill

- `src/dinner-art.js`：共用晚餐資產；沿用 `create-game-assets` 的資產清單／多角度體積原則與 `threejs-materials-lighting` 的材質層次。無引擎升級、全域套件或新增下載。
- `src/tray-rescue.js`：共用救餐時序；`game-feel` 用於預備、接重與確認的停頓。`performance.js` 持有真實掌面／紅色把手錨點，`meal-remnant.js` 據此更新支撐，避免晚一幀移動角色造成穿握。
- `src/story-shots.js`：使用已安裝 `game-cinematic-camera`，按動作目的切近景、跟拍、靜止與拉回，並進行獨立唯讀審核。`creature-communication.js` 和 `damage-appearance.js` 是本輪小型模組，分別負責emoji安全區與持續的受損外觀。

接口僅增加既有特效update的選用camera參數、角色的受損狀態方法及唯讀測試資料，沒有變更外部API、資料庫、存檔格式或部署設定。

瀏覽器為 Chromium／SwiftShader 模擬視窗，**尚未驗證iPhone Safari真機、手機GPU效能或FPS改善**。正式網站未變更；Cloudflare部署結果以此提交SHA對應的GitHub檢查為準。

保險與笑點課本輪只做[美術、裝潢與鏡頭提案](UPSTAIRS-ART-PROPOSAL.md)，尚未改建場景。可調參數集中於出生11.5秒、救餐17秒、emoji各停留區間、鏡頭FOV與托盤支撐高度。
