# 第六輪：梨花、機房與互動砲擊

本輪將晚餐短劇接到單一路線的機房事件。主要實作、本機功能與構圖驗證已完成；公開部署結果等待發布後補記。

## 目前行為

- 玩家先選熱便當、飯糰或甜點，使用對應道具與短反應，之後進入同一條主線。
- 便利店側面有盛開梨花。二樓一間房露出伺服器與異常燈光。
- 莊與弭弗通訊後充能三十秒，充能期間持續接續台詞。
- 玩家點建築選目標，再按力度條砲擊。邊緣失鎖，中央命中，正中央威力最高。
- 有效命中改變真實建築部件，留下破口與碎塊。主砲耗盡時任務停在 99%，剩下仍在運作的伺服器。
- 玩家再次完成力度條，發射龍泡泡。完整飛行、撞擊、返回與落地後，任務才到 100%。
- 重播會恢復建築、伺服器、人物、道具、特效、第一個攻擊目標及進度。結束後場景繼續待機與閒聊。

## 實作範圍

`mission-state.js` 以同一場景時鐘管理台詞、選餐、三十秒充能、力度判定及最後演出；`mission-director.js` 負責相機、角色、破壞與特效接續。沒有新增 Renderer、主渲染循環或獨立劇本計時器。

商店分為六組可破壞的實際場景部件。原始玻璃、樓體、招牌與室內商品會移動並消失，留下實例化碎塊、斷梁及招牌殘片；最後的機櫃使用獨立電源，擊中後關閉並拆成碎片。重播使用保留的物件恢復，不重建整個場景。

梨花的花、葉及落花使用共用幾何與實例。花朵數依畫質為 720／1350／1800，砲擊特效的粒子也有數量上限。莊的升空與龍泡泡的位置分開控制，原始 GLB 未改動。

## 驗證方法

`scripts/browser-v6.py` 使用本機 Chromium、Playwright 與 SwiftShader，採 390×844 直式及 844×390 橫式。這是桌面瀏覽器測試，不是 iPhone Safari 真機驗證。

測試包含模型與單一 Canvas、三種晚餐選擇、無限等待選餐、完整三十秒充能、暫停、實際觸控砲擊、MISS 判定、拖曳／雙指取消防誤射、建築破壞、99% 最後一擊、九秒飛行與三秒落地、伺服器熄滅、重播、Context Lost 恢復及畫面擷取。

完整測試預設在結尾持續觀察六十秒，並記錄實際新增影格與人物姿勢變化。若使用 `END_OBSERVE_SECONDS=0` 進行開發檢查，結果會明確記為略過，不當作六十秒驗證。

已取得以下結果：

- `scripts/mission-check.mjs`：101 項純狀態、劇情資料及輸入時鐘檢查通過，結果為 `artifacts/mission-check.json`。
- `scripts/destruction-check.mjs`：10 項實際場景幾何檢查通過，結果為 `artifacts/v6-destruction-check.json`。此測試以替代 Canvas 畫圖，沒有驗證 GPU 畫面。
- 原始 GLB 與角色控制器的 46 項檢查通過，結果為 `artifacts/v6-cinematic-check.json`。模型雜湊維持不變。
- `scripts/browser-v6.py`：第一輪桌面 Chromium／SwiftShader 的 61 項功能檢查通過，沒有 JavaScript、Shader 或 WebGL 錯誤。結尾實際觀察 60.00 秒，新增 79 個影格，約 1.32 FPS；這是軟體渲染結果，不能當作手機成績。
- `scripts/visual-v6.py`：正式 `/endfield-model-lab/` 子路徑建置的 39 項檢查通過。包含重新整理、三段畫質、人物與龍泡泡的投影代理範圍、臉部避開 HUD，以及砲擊、最後一擊、近景結尾、遠景與橫式構圖。
- 同一支腳本的 `FINAL_COMPLETION_ONLY=1` 模式：最後建置再通過 27 項檢查。實際執行最後一擊及落地，確認可見的「100% · 任務完成」、完成進度條、結尾字幕接續、直橫式字幕避開散步／聽雨按鈕、重播與子路徑重新整理。結果分別為 `artifacts/v6-visual-results.json` 與 `artifacts/v6-final-build-results.json`。

第一輪畫面審查發現砲擊及結尾的直式構圖需要留更多空間給人物，已調整鏡頭並取得上述構圖檢查結果。快速略過最後對話時，也會在發射前更新機櫃位置；測試中龍泡泡在撞擊前與已下降的機櫃相距約 0.011 公尺。

實際本機 WebGL 截圖包含：

- `artifacts/v6-pear.png`：梨花區。
- `artifacts/v6-charge.png`：充能與人物升空。
- `artifacts/v6-combat.png`：可操作力度條與完整店面。
- `artifacts/v6-finale-shot.png`：龍泡泡實際飛行。
- `artifacts/v6-complete.png`：落地後可見的 100% 任務完成。
- `artifacts/v6-complete-wide.png`：廢墟、人物與梨花的遠景。

截圖來自本機正式子路徑建置，沒有使用生成圖代替網頁，也不宣稱是公開網址或 iPhone 真機截圖。
