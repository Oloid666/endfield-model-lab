# DS、Claude 與本地取證的整合判斷

日期：2026-11-09。基準：`all-baseline-01`，17段、88張圖、25項問題及候選改善。DS與Claude文字由使用者提供，不把兩者的建議當作重新跑過遊戲的測試結果。

## 判斷方式

依序檢查：是否有畫面／狀態證據、是否已有實作、是否符合故事、能否小範圍驗收、是否值得手機成本。兩個模型都提到，只表示值得關注，不增加證據強度。沒有影片的項目不補節奏分，也不推估留存率。

Claude較適合這次工作的部分是把「先讀證據，再看反應」、直屏安全區、重要鏡頭分級與驗收串起來；DS補充了聲音、重量和輸入回饋，但多數仍是一般性設計選項，需要先核對既有功能。

**必須修正一個提案中的故事混淆：莊的晚餐與塞西的微波便當是兩份食物。** 莊的晚餐應完整、值得拯救，經過龍泡泡與紫色生物保管後歸還；焦黑、變成紫色生物的是塞西的便當。不能照搬「同一份晚餐完好→焦黑→歸還」。
