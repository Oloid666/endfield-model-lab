# V7 · 玩法試驗區與砲擊演出

本版保留 Three.js、Vite 與原始莊芳宜 GLB。首頁先讓玩家自由看模型，按「去買晚餐」才推進故事。「玩法試驗區」列出六種可操作的簡易原型；這些原型尚未接成完整支線。

## 首頁與試驗區

- 可直接試玩：出力與校準、息壤回收壓縮、洗衣機配重與排水、便當分區加熱、限次掃描，以及旋轉封箱。
- 六種原型各有操作規則、成功、失敗、重試與分數。暫存最高分只保留在本次頁面生命週期，不寫入外部服務。
- 原型使用 SVG 與 DOM。共用既有場景時鐘，沒有新增 Renderer、Canvas、RAF 或獨立計時器。
- 打開試驗區會暫停主線及 3D 演出。關閉後保留原本的暫停狀態。背景分頁不更新原型。
- 對話與關卡都屬原創二創。彌弗通訊卡使用原創 SVG 示意像，畫面明確標示「非官方立繪」。

## 主線變更

- 三種砲擊出力：穩壓、強攻、過載。較高出力有較窄判定、較快指針及較大後座。拆除進度也會改變指針速度。
- 指針動畫及輸入判定使用同一組週期、判定區與場景時鐘。每次發射及切換出力都會重新校準指針。
- 蓄電階段持續 30 個有效場景秒。人物升空、拉開射距，原始骨架參與後座，衣髮有程序動態；鏡頭在發射後切換角度。
- 實際店體幾何分段拆除。碎片噴出、落地並留在現場；辨識得出的便利店商品混在殘骸中。梨花區獨立保留。
- 伺服器改為機架、抽取把手、通風孔、網路線、交換器與獨立 UPS 的組合。普通砲擊結束時伺服器仍運作。
- 終結技發射原本的龍泡泡模型。伺服器粉碎後，龍泡泡繼續飛向鄰居牆面，留下實際開孔並卡住抖動。煙霧逐步散開後給特寫。
- 終結飛行為 9 秒。收尾對話另保留 12 秒閱讀四句台詞，才顯示 100% 完成。明確開始散步後，龍泡泡才回到跟隨模式。
- 結尾採用「梨花沒事，就算無損失」的荒謬判定。原本甜點討價還價台詞已移除。

## 驗證邊界

瀏覽器驗證使用桌面 Chromium 與 SwiftShader。手機尺寸、觸控事件及橫直式畫面測試，不等於 iPhone Safari 真機測試。軟體繪圖的 FPS 不可當作手機效能指標。本版仍需 iPhone 真機確認熱度、幀率、Safari 工具列高度與音效手勢。

## 本輪已完成的驗證

- 狀態與幾何檢查共 244 項：主線 116、六種玩法 57、拆除 22、原始角色骨架與特效 49。這些檢查不等於 GPU 或真機測試。
- `scripts/browser-v7.py` 在實際桌面 Chromium / SwiftShader 完成 92 項瀏覽器檢查。六種原型都用實際 DOM 按鈕完成成功流程，另外檢查重試、失敗、主線暫停與原型關閉後停止更新。
- 主線檢查涵蓋三份晚餐的實際道具、通訊示意像、引述與生氣文案樣式、完整 30 秒蓄電、三種出力、邊緣 MISS、實際骨架後座、拖曳與雙指取消不開砲、店體拆除、機櫃存活、玩家發射龍泡泡、鄰居牆面開孔及卡牆、重播和 WebGL context lost / restore。
- 結尾另以真實時間觀察 **60.04 秒**，實際產生 **68 幀**，人物仍持續更新。約 **1.13 FPS** 是此環境的 SwiftShader 軟體繪圖結果，不能推論 iPhone 幀率。
- 完整功能輪使用本機 production build `index-_8hYlpz7.js` / `index-DLSQOmJy.css`。沒有 JavaScript 或 shader error。此輪發現的臉部鏡頭與樹葉遮擋問題，已另排最終構圖檢查，不能將該輪截圖當作最終構圖。

- Vite 目前仍顯示單一 JS chunk 約 1.023 MB、gzip 約 290 KB 的大小提示。本版沒有宣稱已完成載入最佳化。

`scripts/visual-v7.py` 對最終本機 production build `index-Ufsno2o6.js` / `index-DLSQOmJy.css` 完成 **39 項檢查**，沒有 JavaScript、shader 或 framebuffer error。

- 首頁在 390×844 及 844×390 皆沒有橫向溢出。試驗區入口避開模型查看說明、買晚餐、散步及視角列。

- 最後實際完成到 100%，鄰居開孔持續存在。重播後店體、機櫃、初始目標與鄰居牆面都復原。
