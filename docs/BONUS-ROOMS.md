# 二周目：樓上請

本輪新增左室「笑點解析小教室」與右室「事故調查暨理賠中心」。

## 入口與保存

在開場待機或結局自由活動，點 711 正面或側面招牌七次。可先用街角／店內視角找招牌，單指點實際招牌，不是按視角切換七次。拖曳與雙指不計數；點其他場景物件歸零。結局倒在地上的原招牌也能解鎖。第七次短閃後，右上出現「二周目・樓上請」。第一次進入有劇透提醒。

解鎖、提醒、已讀課程、試辦過的玩法與偏好，以 `rainy711.bonus.v1` 記在此瀏覽器。主線重拍不清除；禁止本機儲存時仍可在當次使用。沒有伺服器或自動上傳。

## 教室

八章各有原句、三頁詳解與角色補刀。課程不計分、不自動翻頁，可以自由重聽。黑板只列重點，手機的 HTML 面板負責完整閱讀；「看黑板」切到近景。補刀改為逐句手動回應，聽到最後一句才記為已讀。黑板依序揭示關鍵詞與診斷，最後一頁先停頓再拉平生命線。

核實來源：

- [BIPM：SI prefixes](https://www.bipm.org/en/measurement-units/si-prefixes)：M 為百萬前綴。
- [《科學超電磁砲》官方第 22 話](https://toaru-project.com/railgun/story/22.html)：Level 6 名詞。
- [國立臺灣歷史博物館：從小甜甜到小女警](https://women.nmth.gov.tw/?p=1913)：結尾語的作品背景。

核對日期：2026-10-27。未確認的將軍口號、最後子彈、歌詞、舟禮最早出處、停服事件不指定來源。PHP 漏洞、主角年齡、Astra 與算力用量只按現有創作台詞處理，不宣稱官方事件或實際製作帳單。原有結尾歌詞未改動。

## 理賠中心

固定案件 WUL-711-01：711 雷擊與建物損失。申請書為新增戲內文件，發射紀錄引用主線，前後照片由同版本場景固定取景，不讀取玩家當次命中與照片。

- A「找矛盾」：先選申報欄位，再打開附件，點選「雷是我打的」原句或案發後照片的店面區域。申報與所選證據並排，玩家按「提出矛盾」才判定。其他證詞與梨花保留可作為錯誤選項；兩次選錯提供提示。兩組矛盾成立後可退回補件，或更正後受理。
- B「填單」：原因三選一、責任三選一、損失二選一。18 種組合中，只有人工雷擊／莊方宜／依建物紀錄符合證據；其餘按損失、責任、原因順序列出補件理由。
- 受理不代表核賠。結案書可下載 PNG；支援檔案分享的瀏覽器另有分享按鈕。兩版完成後可記錄偏好，仍須由玩家自行回報。

## 技術與驗證

新增控制器與純資料／狀態模組；二樓為獨立 cutaway 場景，沿用 World 的 renderer 與動畫迴圈。首次進房才建立室內資源；其後重用。二周目 active 時 World 不更新街景／導播，主線暫停，退出前先消耗 source clock 的時間差再還原暫停狀態。主線相機、裁切、散步和控制狀態均保存還原。

- `node scripts/bonus-check.mjs`：解鎖、拒絕儲存、損壞紀錄、課程資料、A 的證據核對與 B 的 18 組結果。
- `python scripts/bonus-browser.py`：真實招牌點擊、課程翻頁、照片、A/B、PNG、重進、刷新保存、橫直屏與主線還原。桌面 Chromium／軟體 WebGL，非 iPhone 真機驗收。
- `python scripts/bonus-evidence.py`：在 Vite dev 下重製固定前後照片。必須同時提交生成的兩張 PNG；它們不是玩家當次照片。
- 瀏覽器腳本可用 `PREVIEW_URL` 指向 dev 網址。受限環境可將 `XDG_CONFIG_HOME`、`XDG_CACHE_HOME` 指向可寫入的暫存目錄。

下一步是讓使用者在 iPhone 比較兩種理賠操作，再決定正式案件數與玩法。此輪沒有替未核實外部梗補造來源，也不包含交接原有的二樓莊頭像重拍。

初版曾通過 888 項程式檢查與 40 項 Chromium 操作；以下為本輪優化內容與最新驗證記錄。


## 演出與閱讀優化（2026-10-27）

- 黑板三段揭示，每章使用自己的關鍵詞；「看黑板」切回演出布局，提供 18px 以上的同步文字重點。龍泡泡分別表現指示、被打斷、轉向鏡頭與收教鞭。完整台詞依舊手動推進。
- 「專心閱讀」讓文字區擴大到畫面約 75%，可選 18／22／26px；偏好與原有解鎖一起保存，舊紀錄自動使用預設值。證據視窗關閉時還原原頁捲動與焦點。
- 理賠 A 必須選出具體原句或照片位置，再確認矛盾。照片下也有等效文字按鈕，供鍵盤或不便點圖的玩家使用。若重製照片，須一併檢查兩個點選區是否仍對準店面與梨花。
- 結案按鈕先進入抬章／落印／出單流程（約 1.15 秒）；落印事件只觸發一次，出單完成才記錄試辦完成。提前返回會取消演出；減少動態模式縮短為 0.15 秒。音效沿用「雨聲與音效」開關，未開啟時不建立音效播放。
- 演出使用單一 World 時鐘，不用額外計時器。`bonus-presentation.js` 的純狀態函式檢查分段時序、落印唯一性、完成與取消；鏡頭目標僅在模式、構圖或尺寸變動時重算。

## 輕鬆課堂版（2026-10-27）

主流程現在只有底部固定位置的主按鈕。進房後按「開講」，同一位置的「繼續」會依序播放原句、解析、角色補刀與下一篇。看滿三個不同篇目即能結業；另外五篇自由看。上一段、選篇、字級、閱讀模式、看黑板、出處與離開都收進右上「選單」。主按鈕不會因文字長度、補刀或換篇移位。

每按一次會累積該段的最高閱讀進度；重看不重複加分。死亡條以約 1.15 秒的漸進動畫追上目標，未完整看完三篇不會到 100%。100% 後在教室的講桌完成蓋章，出示「笑點已死亡」證明。底部「下課・完成」直接回街景；「繼續看」則接剩餘內容，保持 100% 且不再強迫蓋章。已讀、結業與字級偏好保存在此瀏覽器。選單可手動重新上課並歸零死亡條。

原本已讀紀錄仍保留，新短課堂進度使用同一紀錄內的 `course` 欄位；舊版已讀不會讓第一次進入新版直接跳結業。再次開啟會接續尚未確認的段落。

理賠 A／B 仍保留目前玩法。下一版候選見 [理賠中心提案](CLAIMS-NEXT-PROPOSALS.md)，目前推薦三回合談判桌，尚未製作或宣稱已替換。
