# V13：飛行拍照、手機預覽與卡牆收尾

本輪承接已確認文案，完成開場、操作介面與結尾演出調整。

## 變更

- 快速載入時仍有下班／吃飯／加班五天的開場對話。龍泡泡對著櫃檯結帳，莊保留等待位置。
- 街角、店內、人物改為多視角選單。店內有櫃檯、商品、微波爐與海報；人物有半身、側面與龍泡泡。
- 新增實際飛行搖桿：龍泡泡攜相機移向定位圈，抵達後才能進入拍照。快門後由實際取景位置飛回莊身旁。
- 全畫面手機預覽，新增清晰「確認沒眨眼」人像；它是同一場景重新取景的照片，不是把遠景無限放大。遠景仍可切回與重拍。送出有指尖動畫，再誤切上一張收據。
- 收據補正式編號、711地點、手寫字體簽名；沿用我自己都還沒簽過名與共犯通知笑點。
- 嘆氣與二樓特寫，機房增加書堆、影印機、紙張及網路線。罪名台詞持續震動；減少動態偏好停震。
- 前移地面登入平板，莊不站在上面；六個英文詞塊另加底線與刪除鍵，錯誤組合可退格。密碼便條與多餘數字保留。
- 起飛補天師樁由下往上與鞋子吐槽；戰鬥左右角度輪替，屋頂飛高、碎片分批落地。結尾沿用碎片池再做有限時間的滾落，不增加無限粒子。
- 缺電時保留殘光，天師樁有 LOW 閃爍；最後一發另有較快的個人充能、Level 6笑點、龍泡泡發抖線。
- 倒帶延長為10秒，監視器轉向店內並給特寫；賽希增加手機視角，停服／PHP文案調順。PHP設定仍屬虛構劇情。
- 微波爐顯示800 W／800 MW，按鍵固定在可見區域。第一輪劇情失敗保留；後續提高起始節奏與判定要求，失敗降速放寬。
- 結尾34秒：伺服器、莊、廢墟、招牌、梨花、後方破洞與髒兮兮龍泡泡。保留已確認歌詞字幕、擺動與原創簡短合成音；沒有原曲錄音，聲音仍需玩家開啟。
- 修正V12後方破洞房間與舊實心背景樓重疊。V12結尾曾被牆遮擋；本輪以實際截圖驗證龍泡泡入鏡，補光並拉遠保留破洞。
