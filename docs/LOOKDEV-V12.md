# V12：龍泡泡跑腿與連續分鏡

本輪把開場移動交給龍泡泡。莊留在店外，取消劇情中的逐幀 teleport；自由散步沿用已有步態、落腳與碰撞。

## 已實作

- 龍泡泡經入口飛進店內，貨架／櫃檯鏡頭輪替，提著立體餐袋出門。
- 立體相機、飛遠取景、玩家旋轉／縮放取景、快門後2.5秒飛回莊旁、並肩看照片。快門一次性提高解析度（長邊最多2048像素），PNG保存，再恢復畫質；預覽限制2倍，不宣稱無限放大。
- 預覽明寫確認沒眨眼、傳給管理員證明有吃飯。送出後在手機框顯示下一張簽收單，加入711地點與「我自己都還沒簽名過」。刪除晚餐備註。
- 收手機／嘆氣、二樓機房特寫、通訊接入。莊回覆有實際模型渲染肖像，姓名／通訊標頭同步切換；弭弗A肖像保留內嵌備援與非同步載入隔離。
- 下一句恢復劇情鏡頭，手動拖曳交還玩家；拍照／登入等操作不觸發此規則。「幫我找一條罪名」大字及短震動，減少動態模式停震。
- 登入前3秒鍵盤落地展開，系統提示後才開放操作。驗證保留背鍋笑點，拉桿完成才起飛。
- 起飛腳部、全景、龍泡泡追上、環繞與戰場鏡頭；天師樁特寫保留。
- 三小時前賽希買晚餐、查附近供能與賽馬娘停服看到漏洞的前因。PHP設定是虛構二創，並非真實漏洞公告。
- 四塊彎線組成連續U形路徑，需提交測試；錯誤不退關，第二次提供完整圖示提示。
- 龍泡泡保持在莊身旁；最後裝填掛在骨架手腕位置，表情錯愕。鄰屋移至店後方，整場固定位置，不在發射時搬動。
- 原有爆炸、落地招牌、碎片與持續待機保留；結尾補落地招牌和完好的梨花鏡頭，最後仍停在卡牆龍泡泡。

## 驗證

Node狀態58項、鏡頭70項，以及原有骨架69項、破壞36項、場景道具51項、著色器準備15項、特效25項均通過。完整瀏覽器38項通過，結尾實際觀察60.03秒，無JavaScript錯誤。結果見 `artifacts/v12-browser-results.json`，包含真實DOM操作、劇情時鐘推進及結尾60秒觀察。這是Chromium軟體WebGL，沒有iPhone真機效能結論。

## 限制

模型沒有原生動畫，走路與抓取沿用程序骨架姿勢；相機和餐袋為程序幾何。龍泡泡第一人稱取景用OrbitControls旋轉／縮放／平移，沒有另加飛行搖桿。最終彈道保留誇張弧線，鄰屋在店後方，未宣稱真實彈道物理。高解析度快門可能在手機產生短暫停頓，需iPhone實測。主程式仍有Vite大於500KB的提示。

最後通訊對比與頭像載入複查見 `artifacts/v12-final-visual.json`。
