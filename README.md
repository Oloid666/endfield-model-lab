# 終末地模型實驗室｜Endfield Model Lab

以 iPhone Safari 為優先的終末地模型、場景與互動實驗專案。

目前場景：《莊的晚餐｜雨夜711》。

**[開啟網站](https://oloid666.github.io/endfield-model-lab/?v=7)**

第七輪：首頁可不限時看模型，再按「去買晚餐」開始。主線新增通訊示意肖像、台詞強調、三種砲擊出力、明顯後座、商品與碎片散落。龍泡泡擊穿伺服器後卡進鄰居牆洞，梨花無損即判定無損失。

首頁「玩法試驗區」有六種可玩的操作原型：砲擊校準、息壤壓縮、洗衣失衡、分區加熱、商品掃描、整店封箱。各有成功／失敗、重試與返回。這些是獨立操作試作，完整支線故事尚未接入。

本輪實作、測試與發布狀態見 [第七輪紀錄](docs/LOOKDEV-V7.md)。既有薄玻璃、商品、自然待機與散步跟隨沿用。

## 啟動

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

預設相對資源路徑。GitHub Pages 工作流程使用 `VITE_BASE_PATH=/endfield-model-lab/`。模型依 `import.meta.env.BASE_URL` 載入，沒有路由或後端。

## 操作

- 單指拖曳：旋轉。
- 雙指：縮放與平移。
- 下方按鈕：街角、店前、屋簷、梨花、近看、重設。可以雙指繼續放大。
- 「散步」：拖曳左下搖桿；電腦也可用 WASD／方向鍵。活動範圍是店內與騎樓，人物會避開貨架、櫃台與非入口玻璃。龍泡泡會跟隨，進店時鏡頭會調整；手動拖曳仍可接管鏡頭。
- 「去買晚餐」：點擊台詞繼續，或開啟自動。選項會一直等待。
- 右側可暫停／繼續。主線對話可略過本段；充能持續三十個有效秒，終結技完整播放。
- 砲擊：選「穩壓／強攻／過載」，看準力度條中央按「砲擊」；電腦也可按空白鍵。邊緣 MISS 不耗能，中央威力最高。高出力的判定區較窄，後座較強；破壞越多，力度條越快。
- 99% 時推進最後對話，再看準中央按「發射龍泡泡」。飛行、撞擊與戰損對話完成才到 100%。龍泡泡留在鄰居牆洞；按「散步」才回到跟隨。
- 結束後「重新選餐」會復原建築、機櫃與所有進度。
- 結尾後點人物、晚餐、手機或「聽雨」，觸發短對話。主線進行時不會插入閒聊。
- 首頁「玩法試驗區」：選一張卡片開始。試玩時主線與 3D 渲染暫停，關閉後恢復。
- 右上設定：雨、雨聲、人物預覽、畫質與素材來源。

雨聲在使用者開啟後，以 Web Audio 產生。沒有外部音訊、付費 API 或資料追蹤。
