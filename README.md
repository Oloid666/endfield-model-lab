# 終末地模型實驗室｜Endfield Model Lab

以 iPhone Safari 為優先的終末地模型、場景與互動實驗專案。

目前場景：《莊的晚餐｜雨夜711》。

**[開啟 V10 網站](https://oloid666.github.io/endfield-model-lab/?v=10)**

首頁可不限時看模型，再按「去買晚餐」開始。簡短買飯後，玩家控制相機拍照報平安，放大照片選擇先查一樓貨單或二樓機房。萬噸息壤轉運、天災保單與龍泡泡的吐槽貫穿主線。

第十輪加入拍照調查、需要接聽的深色通訊卡、五次大鍵登入、實體監視器、賽希接線與弱密碼笑點、節拍加熱和紫色馬賽克料理。首次加熱為明示的劇情失控，正式挑戰失敗後降低速度、放寬判定。砲擊、天師樁、散步與原模型沿用。

人物載入失敗會在主畫面提供重試，成功前不開空場景劇情。街景先顯示，人物光影與賽希回放分段準備；載入笑話與真實下載／處理階段分開。這不代表 iPhone 效能已通過驗收。

本輪驗證與發布狀態見 [第十輪紀錄](docs/LOOKDEV-V10.md)。

## 啟動

使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

預設相對資源路徑。GitHub Pages 工作流程使用 `VITE_BASE_PATH=/endfield-model-lab/`。模型依 `import.meta.env.BASE_URL` 載入，沒有路由或後端。

## 操作

- 單指拖曳：旋轉。
- 雙指：縮放與平移。
- 下方按鈕：街角、店前、屋簷、梨花、看臉、重設。可以雙指繼續放大。
- 「自動運鏡」：拖曳後停止自動接管，按按鈕恢復當前演出；「自動對話」是另一個控制。
- 「散步」：拖曳左下搖桿；電腦也可用 WASD／方向鍵。活動範圍是店內與騎樓，人物會避開貨架、櫃台與非入口玻璃。龍泡泡會跟隨，進店時鏡頭會調整；手動拖曳仍可接管鏡頭。
- 「去買晚餐」：點擊台詞繼續，或開啟自動對話。拍照、照片放大調查、接聽與小遊戲均等待玩家操作。
- 天師樁接入：依莊的提示點按鍵帽。帳號 `endfield_power`、密碼 `5201314`；可退格修正或重聽。驗證後，把拉桿拖到最右端。帳密只用於本地劇情，不會送往外部服務。
- 右側可暫停／繼續。主線對話可略過本段；充能持續三十個有效秒，終結技完整播放。
- 砲擊：選「穩壓／強攻／過載」，看準力度條中央按「砲擊」；電腦也可按空白鍵。邊緣 MISS 不耗能，中央威力最高。高出力的判定區較窄，後座較強；破壞越多，力度條越快。
- 99% 時先進入 VCR：鏡頭帶向實體監視器，回看賽希接通終端。轉動三塊線路，查看弱密碼。加熱用節拍操作，圓點短按、長條按到尾端；第一輪必定因電網突波失敗，不記操作失誤。後續每段四個提示，命中三個可過關；失敗重試當段並降低難度，完成三段後顯示劇情中的 0.3 秒。
- 回到現場後，看準中央按「發射龍泡泡」。終結技、戰損對話與結尾運鏡完整播放後才進入持續互動。龍泡泡留在鄰居牆洞；按「散步」才回到跟隨。
- 結束後「重拍這個雨夜」會復原建築、機櫃與所有進度。
- 結尾後點人物、晚餐、手機或「聽雨」，觸發短對話。主線進行時不會插入閒聊。
- 右上設定：雨、雨聲、人物預覽、畫質與素材來源。

雨聲在使用者開啟後，以 Web Audio 產生。沒有外部音訊、付費 API 或資料追蹤。
